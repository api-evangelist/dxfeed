# dxFeed

> dxFeed is a market data distributor (a Devexperts subsidiary, Munich HQ) delivering real-time, delayed, historical, and on-demand financial market data across equities, ETFs, futures, options, indices, FX, fixed income, and crypto — 3.5M instruments, ~200,000 simultaneous streaming clients — plus reference data (Instrument Profile Format), Morningstar-sourced fundamentals, options analytics, and news. The developer surface is openly documented but production access is sales-gated: credentials (endpoint URLs, login, password) and per-service entitlements arrive via onboarding. Public no-credential demo endpoints serve delayed data.

Generated by API Evangelist from apis.yml and harvested artifacts (no provider llms.txt exists; kb.dxfeed.com/llms.txt redirects to page-not-found, probed 2026-07-22).

## APIs

- [dxFeed REST Web Service API](https://kb.dxfeed.com/en/market-data-api/data-access-solutions/rest.html): /events snapshots, /eventSource Server-Sent Events streaming, /addSubscription, /removeSubscription across 20+ market event types in JSON or XML. Public demo: https://demo.dxfeed.com/webservice/rest (live help at /help).
- [dxFeed dxLink WebSocket API](https://kb.dxfeed.com/en/market-data-api/data-access-solutions/websocket.html): WebSocket protocol with multiplexed virtual channels, AUTH token flow, FEED and DOM (order book) service channels. Public demo: wss://demo.dxfeed.com/dxlink-ws with a debug console at https://demo.dxfeed.com/market-data/dxlink-ws/debug/.
- [dxFeed Fundamentals API](https://kb.dxfeed.com/en/data/fundamentals.html): Morningstar/Borsa Istanbul fundamentals for ~45,000 companies — 28 datasets (company profile, financial statements, valuation/earning/operation ratios, ownership summaries, corporate actions, IPO and economic calendars, crypto reference) with a uniform /recent/symbol, /symbol, /filter resource pattern. OpenAPI 3.1: https://tools.dxfeed.com/fs/v3/api-docs
- [dxFeed Instrument Profile (IPF) Web Service](https://kb.dxfeed.com/en/data-model/reference-data/ipf-webservice.html): instrument profiles and live incremental updates for the 3.5M-instrument symbology universe (credential-gated at https://tools.dxfeed.com/ipf).
- [dxFeed FIX API](https://kb.dxfeed.com/en/market-data-api/data-access-solutions/fix.html): industry-standard FIX access for trading systems; session hosts provisioned at onboarding.
- [dxFeed Historical Data Services](https://kb.dxfeed.com/en/data-services/historical-services.html): candle/aggregated data and raw tick-data extraction (up to 10TB/day stored) delivered as files.
